          Services

            Admin and Files sign you in automatically

            Opening Admin or Files signs you in to LiteLLM and RustFS with your portal session: no second password. Sign out ends it.

            Credentials (for the API or if automatic sign-in fails)
            Admin (LiteLLM)
            – Its sign-in form ↗
            Files (RustFS)
            – Its sign-in form ↗

            Change them in Settings → Account & security. A password changed inside LiteLLM's own UI is not known here: set it in Settings too, or the automatic sign-in to Admin stops working.

            Maintenance

            One-click updates are off

            ./stack helper install

            The portal cannot install software on your computer (by design), so this one step runs in a terminal, in your bedrock-now folder; then Update, Roll back, Clean up and automatic updates work from Home.

            Automatic updates

            Each action asks for the portal password and is carried out on this computer by the update helper (./stack helper status).

            Claude Code in your terminal

            claude-bedrock

            Runs Claude Code against Bedrock through this stack; plain claude is unchanged. Its spend shows in Bedrock spend, under Claude Code.
